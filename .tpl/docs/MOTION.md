# 动效调查与实现

参考首页及各内页公开 HTML、组件模块与实际页面；PC 1440×1000 已观察，平板与手机的完整逐项对照待补。

| 项目 | 原站证据 | 当前实现与限制 |
| --- | --- | --- |
| 文章图片悬停 | 推荐卡及列表图片组件 | 图片 scale(1.03) .5s，触控无依赖；精确比例/缓动仍待逐帧对照 |
| 菜单 | 左侧菜单触发器 | 侧边滑入、遮罩、Escape、焦点约束；位移/时长尚未完成原站三端实测对照 |
| 搜索 | PC 点击 Search Icon 后出现 dialog + Search... | 搜索对话框、实时筛选、焦点约束；公开脚本 QuickMenu 使用 .95 缩放和 spring(600,40)，现已采用同一缩放与弹簧参数，移动端 FixedTop 差异尚待逐帧对照 |
| 加载更多 | 首页5项初始文章及 LOAD MORE | 5项后显示剩余4项；layout 动效，原站精确布局过渡待对照 |
| 联系玻璃 | 真实 canvas，公开 Fluted Glass fragment 无时间变量 | WebGL2 相同16槽、曲率1.4、折射.11、色散1.54；无时间循环。原 blur/frost 均0，合并重复采样；需三端图形验收 |
| 按钮 | 原站按钮组件 | hover/active 色彩与位移，精确响应待对照 |
| 页面切换、入场与滚动 | 原站页面模块存在空 effect 数组；首页 appear 标记仅推广组件 | 未将推广浮层复制；实际全站切页与滚动效果仍需完整观察，不宣称全部不存在 |
| 减少动态 | 系统偏好 | CSS禁用过渡，Framer Motion减少面板和布局动画 |

不添加未观察到的轮播、视差、拖拽、装饰箭头或视频。当前不能标记完整动效复刻验收通过。
